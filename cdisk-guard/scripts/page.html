✅ 安全度分級：A 檔＝臨時檔／快取／安裝包殘留，可放心刪；B 檔＝軟體資料或自建目錄，需你判斷；C 檔＝系統元件／個人資料／憑證，checkbox 已鎖定，後端也會再次拒絕。預設已勾選所有 A 檔（依設定排除的項目除外）。
⚠️ 此操作非常危險，可能導致不可逆的數據丟失！ 本頁由只綁 127.0.0.1 的本機後端提供，按下「執行刪除」會先弹出確認視窗逐項列出完整路徑；再次確認後直接刪除勾選項目，本工具不主動移入回收站（部分環境下非系統碟仍可能被系統導向該碟回收站）。僅 <100 MB 小項有 ZIP 備份可還原。

一、各磁碟根目錄

依佔用大小排列；系統元件（Windows、Program Files、pagefile.sys 等）歸 C 檔，禁止勾選。

二、各用戶佔用

單次遍歷、排除 reparse point，與其他區塊同一資料來源，不會出現兩套口徑。使用者設定檔總目錄不可整刪。

三、各用戶目錄明細

逐用戶列出第一層目錄內容與佔用；個人文件與憑證目錄一律鎖定。

四、已知垃圾點

系統與應用程式快取、暫存、更新包；A 檔為主要回收來源。

五、AppData 細項

Local／Roaming 第一層子目錄，以及 Temp 下的大型子項。

六、大檔案 TOP

大於設定門檻的單一檔案；安裝包／壓縮檔歸 B 檔，請自行判斷。

七、安全邊界與執行流程

🟢 刪除流程（對應 2026-11-23 實際做法）：① 剔除 C 檔／鎖定項／父子重疊子項／設定排除項 → ② 寫入完整 manifest → ③ <100 MB 小項做 ZIP 備份 → ④ 每批最多 10 項、Python 直接刪除（使用中檔案自動略過） → ⑤ 逐項複核 → ⑥ 同資料來源對比空間 → ⑦ 寫執行紀錄。
🟢 多磁碟：勾選可以跨碟，執行時按磁碟分組、逐碟刪除；每顆碟各有自己的 manifest、備份與逐項紀錄，合計結果另存一份。
🔵 特殊動作：Explorer 只刪 thumbcache_*.db；回收站內容依設定走 SHEmptyRecycleBinW（只清本碟）；他人 SID 的回收站殘留只回報、不清除。
🔴 不可逆：本工具直接刪除、不主動移入回收站；但部分環境（非系統碟、第三方檔案篩選）仍可能被系統留一份在該碟回收站，實際殘留以「回收站殘留」為準。觀測淨增受其他程式寫入影響，與帳面目標值分開呈現。

# DiskGuard 功能优化与改进建议备存

> 整理日期：2026-11-28  
> 项目参考：https://github.com/Wahero/DiskGuard  
> 用途：日后功能优化、迭代规划与改进参考

---

## 一、背景说明

DiskGuard 的独特定位在于：

- **桌面宠物形态**：以友好、低打扰的方式陪伴用户；
- **被动式磁盘空间守望者**：不主动强制清理，而是提示、建议和守护；
- **极致安全承诺**：完全离线、绝不自动删除、清理项进行安全分级。

因此，后续功能优化不应把 DiskGuard 做成另一个通用“清理器”，而应持续强化其核心定位：

> **安全、友好、智能的桌面磁盘空间伴侣。**

---

## 二、GitHub 同类项目概览

### 1. 开发者专项清理

- **degunk / dev-prune**
  - 扫描 `node_modules`、`.venv`、`target` 等可重建构建产物；
  - 通过 Git 状态和锁文件严格验证安全性后再删除。
- **git-reclaim**
  - 聚焦 Git 仓库本身；
  - 通过清理缓存目录和压缩历史释放空间。
- **githawk**
  - 分析 Git 仓库历史；
  - 找出已从工作区删除但仍占用空间的历史大文件。

### 2. 系统级综合清理

- **OmniClean**
  - Go 编写的终端 UI 工具；
  - 整合多种包管理器卸载、残留检测、项目产物清理和磁盘分析。
- **rust-space-cleaner**
  - Rust 开发的终端工具；
  - 扫描开发、游戏、Web、系统等多类垃圾来源；
  - 默认“试运行”模式，安全系数高。
- **Jharu**
  - 面向开发者和 ML 工程师的桌面应用；
  - 可清理 Hugging Face、Ollama 等 AI 模型缓存及包管理器缓存。

### 3. 磁盘分析可视化

- **gdu / dua-cli / dust**
  - 快速终端磁盘分析器；
  - 用于定位大文件和大目录。
- **WinDirStat / QDirStat**
  - 经典图形化磁盘空间可视化工具；
  - 通过树状图直观展示空间占用。

## 三、DiskGuard 功能建议

### 1. 增强“守护感”：更智能的预警与可视化

#### 1.1 动态空间预测

基于历史磁盘使用数据，预测磁盘空间耗尽时间，例如：

> “按当前速度，约 15 天后 C 盘空间将低于 1%。”

价值：

- 让预警更具前瞻性；
- 强化“守望者”而非“清理器”的定位；
- 提升用户对磁盘趋势的感知。

#### 1.2 轻量级空间占用可视化

在点击桌面机器人弹出的面板中，加入简化版可视化，例如：

- 环形图；
- 矩形树图；
- 分类占比图。

展示维度建议：

- 系统；
- 应用；
- 文件；
- 其他。

价值：

- 比纯数字列表更直观；
- 保持轻量，不引入复杂磁盘分析器体验；
- 与桌面宠物交互自然结合。

---

### 2. 深化“安全清理”：更细粒度控制与追溯

#### 2.1 清理规则自定义

允许用户为 A/B/C 级分类自定义规则，例如：

- 将“超过 30 天未访问的 Downloads 文件夹”设为 B 级（建议清理）；
- 将特定目录加入白名单；
- 调整不同分类的提醒阈值。

价值：

- 让安全分级更贴合个人习惯；
- 在不破坏安全承诺的前提下提升灵活性；
- 避免“一刀切”规则导致误判。

#### 2.2 清理历史与一键“后悔”

增加可视化清理历史面板，并支持恢复能力：

- 展示历次清理记录；
- 标记可恢复项；
- 支持一键恢复某次清理中的文件（前提是备份仍存在）。

价值：

- 强化“永不担心误删”的心理安全感；
- 让安全承诺可感知、可验证；
- 与“绝不自动删除”的定位形成闭环。

---

### 3. 扩展“能力圈”：在安全前提下做更多

#### 3.1 开发者缓存识别

在清理清单中扩展对开发者可重建目录的识别，例如：

- `node_modules`；
- `.venv`；
- `pip` 缓存；
- 其他项目构建产物。

安全策略建议：

- 始终归为 **B 级（需确认）**；
- 清晰说明“此项为项目构建产物，可安全重建”；
- 不默认勾选、不自动删除；
- 可结合 Git 状态、锁文件等做安全性验证。

价值：

- 覆盖开发者用户；
- 增强项目实用性；
- 同时保持 DiskGuard 的安全边界。

#### 3.2 多磁盘 / 关键目录监控

当前可专注 C 盘，后续可允许用户：

- 添加其他盘符；
- 添加关键目录，例如 `D:\Games`；
- 为不同磁盘或目录独立设置预警阈值。

价值：

- 扩展监控范围；
- 保持轻量，不做重型全盘清理；
- 满足多分区用户的实际需求。

---

### 4. 保持“无扰”体验：优化交互与资源占用

#### 4.1 智能免打扰模式

在“电脑闲时分析”之外，增加：

- 全屏应用时暂停弹窗；
- 游戏时暂停动画和提醒；
- 可配置免打扰时间段。

价值：

- 确保沉浸式场景零打扰；
- 符合桌面宠物“陪伴但不打扰”的定位；
- 提升长期驻留意愿。

#### 4.2 极致的资源占用优化

提供“极简模式”：

- 降低磁盘状态轮询频率；
- 降低动画帧率或关闭动画；
- 减少后台 CPU / 内存占用；
- 保留核心预警能力。

价值：

- 强化“无感守护”；
- 适合常驻后台；
- 降低用户对桌面宠物类工具的 resource 顾虑。

## 四、优先级建议

| 优先级 | 功能方向 | 建议功能 | 理由 |
|---|---|---|---|
| P0 | 安全与信任 | 清理历史与一键“后悔” | 直接强化核心安全承诺，形成差异化 |
| P0 | 守护感 | 动态空间预测 | 提升预警前瞻性，贴合守望者定位 |
| P1 | 交互体验 | 智能免打扰模式 | 降低打扰，提升长期驻留 |
| P1 | 安全控制 | 清理规则自定义 | 提升灵活性与个人适配度 |
| P1 | 可视化 | 轻量级空间占用可视化 | 提升信息可读性，保持轻量 |
| P2 | 能力扩展 | 开发者缓存识别 | 覆盖开发者用户，但需严格安全分级 |
| P2 | 能力扩展 | 多磁盘 / 关键目录监控 | 扩展场景，但需控制复杂度 |
| P2 | 性能体验 | 极简模式 | 强化常驻后台体验 |

---

## 五、总体结论

DiskGuard 无需在“清理能力”上与专业清理工具正面竞争，而应持续强化其独特定位：

> **安全、友好、智能的桌面空间伴侣。**

后续优化建议围绕以下方向展开：

1. **更前瞻的预警**：动态空间预测；
2. **更细的安全控制**：自定义规则、清理历史与恢复；
3. **更自然的可视化**：轻量空间占比展示；
4. **更广的覆盖**：开发者缓存、多磁盘监控；
5. **更无感的体验**：免打扰模式、极简资源占用。

通过以上改进，DiskGuard 可以在保持安全、离线、不自动删除的前提下，建立更清晰的差异化价值。

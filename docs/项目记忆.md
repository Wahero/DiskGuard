## 二、v1.1.0 已完成

### 桌宠形象与交互

- 猫耳改为圆弧机械耳壳，增加内耳阴影与暖色反光。
- 默认视觉比旧版小 10%。
- 左键抓起时放大 12%，新增抬手、睁眼、小嘴与减轻落地阴影的形象。
- 用量面板根据猫的位置自动避让。
- 面板文字增加 2 px。
- 更新表情总览、抓起动作预览和托盘图标。

### 扫描与空间计算

- 每个文件只 stat 一次，大文件 mtime 只有进入 TOP 时才计算。
- 保存原始字节，显示时才转换 MB／GB。
- 时间预算使用 monotonic clock，同时按目录和项目数量检查。
- 截断扫描不覆盖完整 baseline。
- 报告使用原子写入，模板单次 token 注入。

### 删除安全

- 显式栈安全遍历，递归前剪除 reparse point。
- 扫描过期、目标变成链接、输出目录与目标重叠时拒绝删除。
- 备份归档名加入目标前缀，避免重名覆盖。
- 备份 I/O 不完整时阻止删除。
- 线程锁与跨进程文件锁防止并发删除。
- thumbcache 按实际残留数量复核。
- 前端与后端有效释放量统一按本批选择计算。

### 性能与资源

- 精灵缓存改为 8 MiB LRU。
- 相同画面不重复绘制，拖动和警示移动期间只移动窗口。
- 长扫描独立线程，不阻塞进度轮询和服务器管理。
- worker 的 UI 操作投递回 UI 线程。
- 配置未变化时只 stat，JSON 未变化时不重复解析。
- 心跳只有一个所有者。
- manifest 使用摘要 checkpoint＋追加式逐项 journal。
- 托盘图标每种造型只渲染一次。
- 音效先节流再访问文件系统。
- 渲染 CPU 实测降低约 18.2%，144／144 像素哈希一致。

## 三、关键架构决策

1. **SQLite 只能作为派生索引，不能成为唯一审计真相。**
   - 现有 JSON、JSONL journal、Markdown 和 ZIP 仍是权威附件。
   - SQLite 损坏必须可从原始文件重建。

2. **DiskGuard 不是备份工具。**
   - 不承诺完整恢复。
   - 不做一键恢复、云备份、外部硬盘备份或 VSS。

3. **ZIP 备份改为可选，默认关闭。**
   - `delete.backup_enabled=false`。
   - 只有用户明确启用时才为符合条件的小项创建本机 ZIP。
   - 关闭时不进行备份 IO。

4. **备份不完整不能删除。**
   - 空间不足时禁用备份与最终确认，不允许静默降级为无备份删除。
   - 写入不完整时，删除尚未开始即中止。

5. **最终删除必须重新即时验证。**
   - 不信任前端预览。
   - 再检查扫描时效、目标存在性、reparse point、输出目录重叠和互斥锁。

6. **历史页故障不能阻塞删除。**
   - SQLite 故障进入降级模式。
   - 删除继续写 JSON／journal。

7. **所有服务只绑定 `127.0.0.1`。**
   - 不引入遥测、账号、云同步或外部网络请求。

## 四、v1.2.0 已冻结范围

### P0 功能

1. 清理历史与审计页面。
2. 现有审计文件自动索引、迁移与去重。
3. 历史列表、筛选、分页与详情。
4. 后端统一删除前风险预览。
5. 可选 ZIP 备份，默认关闭。
6. LOW／MEDIUM／HIGH 分级确认。
7. SQLite 损坏重建与降级模式。
8. 测试、文档和发布。

### 明确不做

- 动态空间预测。
- 轻量级空间占用可视化。
- 一键恢复或完整备份。
- 关键目录监控。
- 自动删除。
- 通用清理器。
- 开发者缓存识别扩展。
- 账号、遥测、云同步。

完整内容见：`docs/DiskGuard_下一阶段开发计划_PRD.md`。

## 九、发布流程

1. 更新 `cdisk-guard/VERSION`。
2. 更新 `README.md` 与 `CHANGELOG.md`。
3. 运行全部自测。
4. 提交并推送 `main`。
5. 创建 annotated tag：`git tag -a vX.Y.Z -m "DiskGuard vX.Y.Z"`。
6. 推送标签。
7. 使用 `git archive` 生成干净 ZIP，确保不含 `cdisk-guard/data/`。
8. 计算 SHA256。
9. 使用 `gh release create` 发布并上传 ZIP。
10. 验证 Release 为 Latest、资源哈希正确、工作区干净。
